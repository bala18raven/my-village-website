# Village Website Starter

A responsive village heritage website built with plain HTML, CSS and JavaScript, ready for GitHub Pages.

## 1. Preview locally
Open `index.html` in your browser, or use the Live Server extension in VS Code.

## 2. Personalize it
- Replace `[Your Village Name]` and the sample text in `index.html`.
- Put your photos in the `images` folder using the filenames below.
- Update the village location and Google Maps link in `index.html`.
- Change colours and typography in `style.css` if desired.

## 3. Photo filenames
- `hero-village.jpg` — wide landscape for the homepage
- `temple.jpg`
- `fields.jpg`
- `village-street.jpg`
- `festival.jpg`
- `gallery-1.jpg` through `gallery-4.jpg`

Use JPG or WebP images, ideally optimized for the web. Keep filenames lowercase and use hyphens, and make sure the names in HTML match exactly.

## 4. Publish on GitHub Pages
1. Create a GitHub repository, for example `my-village-website`.
2. Upload all files and the `images` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for deployment, then open the URL shown in the Pages settings. A project site normally uses `https://YOUR-USERNAME.github.io/my-village-website/`.

## 5. Update later
Edit files locally and upload/commit the changes to GitHub. GitHub Pages republishes the site after the changes are pushed.

## Important
This starter is static: there is no admin login or database. To update content without editing code, connect a CMS or add a backend later. Do not put private information, passwords, or sensitive personal details in a public repository.
